Rust pour la robotique temps réel

Un cours complet pour débuter Rust, du langage jusqu'aux implémentations de filtre de Kalman et de cinématique directe/inverse. Pensé pour qui connaît déjà un peu le C/C++ : chaque notion est reliée à un exemple concret de robotique.

Comment suivre ce cours ? Lis les chapitres dans l'ordre. Chaque page contient de la théorie, des exemples de code commentés, des encarts « ⚠️ Piège C/C++ → Rust » et des exercices. Les solutions sont repliables : essaie d'abord, puis clique sur « Voir la solution ». Installe Rust avec rustup.rs et teste chaque exemple dans un projet cargo.
